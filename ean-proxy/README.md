# EAN Proxy API

Proxy simples para consulta de produtos por código de barras (EAN/GTIN),
usando a API pública do OpenFoodFacts.

## Endpoints

### Descrição do produto
/api/ean?tipo=descricao&codigo=7891000315507

### Imagem do produto
/api/ean?tipo=gtin&codigo=7891000315507

## Deploy

1. Suba este repositório no GitHub
2. Importe no Vercel
3. Aguarde o deploy
4. Use o domínio gerado ou o domínio personalizado

## Requisitos
- Node.js 18+
